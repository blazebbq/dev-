API Documentation

The Stock Management System provides a comprehensive REST API for all operations.

Product Endpoints

GET /api/products - List all products
POST /api/products - Create a new product
GET /api/products/{sku} - Get product details
PUT /api/products/{sku} - Update product
DELETE /api/products/{sku} - Delete product

Stock Endpoints

GET /api/stock/levels - Get all stock levels
GET /api/stock/levels/{sku} - Get product stock level
POST /api/stock/receipt - Record stock receipt
POST /api/stock/issue - Record stock issue
POST /api/stock/transfer - Transfer between warehouses
POST /api/stock/adjust - Adjust stock quantity
GET /api/stock/low-stock - Get low stock items

Warehouse Endpoints

GET /api/warehouses - List all warehouses
POST /api/warehouses - Create warehouse
GET /api/warehouses/{code} - Get warehouse details

Reporting Endpoints

GET /api/reports/inventory-valuation - Inventory value
GET /api/reports/stock-movement - Movement history
GET /api/reports/warehouse-utilization - Warehouse stats
GET /api/reports/abc-analysis - ABC classification

Quick Start Guide

1. Initialize the Database

python init_db.py

2. Start the Server

python app.py

3. Test the API

curl http://localhost:5000/api/health
curl http://localhost:5000/api/products
curl http://localhost:5000/api/stock/levels

4. Create Your First Product

curl -X POST http://localhost:5000/api/products \
  -H "Content-Type: application/json" \
  -d '{
    "sku": "PROD100",
    "name": "My Product",
    "description": "Product description",
    "unit_price": 99.99,
    "reorder_point": 50,
    "reorder_quantity": 200
  }'
